# Maia additional assets

Interactive walkthroughs and reference pages that explain how Maia works, how it is secured, and how to adopt it. Each page is a single, self-contained HTML file hosted on GitHub Pages.

## Contents

| Asset | What it covers | Best for |
|---|---|---|
| **[Maia getting started](https://garniebolling-maia.github.io/additional-assets/maia-best-practice-build-flow.html)** | A step-by-step path from setup to production. Shows where Maia Team, your own standards and the built-in controls fit at each stage: foundations, standards, planning, building, validating, releasing and monitoring. | Teams new to Maia |
| **[Maia architecture](https://garniebolling-maia.github.io/additional-assets/maia-architecture-diagram.html)** | An interactive view of how Maia fits together for Hybrid SaaS and Full SaaS: what runs where, how data flows, how TLS protects each connection, and the controls you have. | Architects and security reviewers |
| **[Maia security and AI questions](https://garniebolling-maia.github.io/additional-assets/maia-security-and-ai-questions.html)** | Answers on data handling, AI features, access, deployment options and compliance. Includes 25 questions with topic filters and links to the Trust Center. | Security and procurement teams |
| **[Maia and DevOps](https://garniebolling-maia.github.io/additional-assets/maia-devops-git-workflow.html)** | How Maia works with your Git platform, including GitHub and Azure DevOps. Follows a change from main to a branch, through commit, push and pull request, back with a pull, and out as a published artifact promoted across environments. | DevOps and platform teams |
| **[Maia star schema build flow](https://garniebolling-maia.github.io/additional-assets/maia-star-schema-build-flow.html)** | How Maia fits around an existing star schema, from your design through loaded, scheduled and monitored dimensions and facts. | Data engineers and modelers |
| **[From Matillion ETL to Maia](https://garniebolling-maia.github.io/additional-assets/maia-matillion-etl-to-maia.html)** | A guided path for Matillion ETL customers: what carries over, what changes, and where Maia Team helps, from concept mapping through the Upgrade Assistant, validation and release. | Matillion ETL customers |

## Using the pages

- Open any link above in a browser. No installation or sign-in is needed.
- To open a page in a new tab, Ctrl-click (Cmd-click on Mac) the link.
- The walkthroughs have a **Start** button and support the left and right arrow keys.
- The architecture page has a **Hybrid SaaS / Full SaaS** switch and a **Show TLS** button. Select any component to see what it does and which controls apply.

## Notes

- The pages summarize the Maia documentation as of November 2026. Capabilities vary by plan and data warehouse.
- The security and architecture pages are not a contractual commitment. The [Matillion Trust Center](https://www.matillion.com/trust-center) and your agreement are authoritative.
- For full product details, see the [Maia documentation](https://docs.maia.ai).
